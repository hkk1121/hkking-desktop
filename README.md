# GPT小龙娘桌面版

hkking 的 GPT小龙娘桌面版发布页，这里提供安装包下载，源码在 [dragonpet-desktop](https://github.com/hkk1121/dragonpet-desktop)。

一只住在 Windows 桌面上的龙娘桌宠：会自己走来走去、伸懒腰、读书、打瞌睡，饿了会噘嘴，被冷落了会委屈；眼睛会跟着鼠标转，你打字时她也坐下来敲键盘；摸她、喂她、甩她都会用语音回应你。接上 GPT 后还能打字或按住快捷键语音和她聊天，让她帮你开软件、设提醒、放歌、调音量、操作窗口和浏览器。

> 手机版见 [GPT小龙娘安卓版](https://github.com/hkk1121/hkking)。作者：hkking，使用 AI 制作（vibe coding）

## 下载安装

1. 打开 **[Releases](https://github.com/hkk1121/hkking-desktop/releases/latest)**，下载最新的 `GPT小龙娘桌面版-安装包-vX.X.X.exe`（另外两个文件是应用内更新用的，不用下载）。
2. 双击安装，需要 **Windows 10 / 11（64 位）**。默认装在当前用户目录下，不需要管理员权限，也可以自己选安装位置。

> 安装包约 1.9GB（几十个动作、一万多帧动画和本机语音识别模型都在里面），建议连 Wi-Fi 下载。国内访问 GitHub 较慢时可以多试几次。
>
> 安装包没有代码签名，运行时 Windows 可能提示「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」即可；个别杀毒软件可能误报，请放行。

## 首次设置

第一次启动会弹出设置窗口，以后右键小龙娘选「设置...」也能打开。改完点 **「保存」** 立即生效。

**聊天接口**（不聊天可以不填）

| 项目 | 说明 |
|---|---|
| API Key | 接口密钥，如 `sk-...` |
| API 地址 | OpenAI 兼容接口地址，一般以 `/v1` 结尾，如 `https://api.openai.com/v1` |
| 代理地址 | 留空使用系统代理；系统代理没开时填本机代理，如 `http://127.0.0.1:7890`。检查更新也走这个代理 |
| 模型 | 填好 API Key 后自动读取可用模型，在下拉框里选，也可以手动填写 |

**外观与行为**

| 项目 | 说明 |
|---|---|
| 体型 | 小 / 中 / 大，按她所在屏幕的高度缩放（约占屏幕高的 20% / 30% / 40%），1080P 到 4K、不同缩放下看起来一样大，最大为素材原图大小，不会发糊 |
| 活动屏幕 | 接了多块屏幕时出现，指定她待在哪块屏幕上，走动、偷看、拖拽都不会跑到别的屏幕 |
| 自由走动 | 关掉后她会安静待在原地 |
| 放哪停哪 | 拖到哪里轻轻松手就停在哪里，用力甩还是会掉下去；右键菜单「回到地面」或跟她说「下来」就掉回地面 |
| 跟随鼠标 | 鼠标在旁边移动时，她转头看向鼠标 |
| 站在窗口上 | 被甩出去或走动时可以落在窗口顶上、跟着窗口走；拖到窗口左右边缘松手会从窗口后面探头（要开着边缘偷看） |
| 边缘偷看 | 鼠标在屏幕左、右、上边缘停一秒时，她从那条边探出头来偷看 |
| 固定在 GPT 里 | 待在 ChatGPT 桌面版窗口底部，跟着窗口移动和最小化 |
| 置顶档位 | 低：会被别的窗口盖住，点她才到最前面；中（默认）：一直在最上面，被别的软件抢走置顶时马上夺回；高：强制置顶，全屏游戏里也显示，鼠标点不到她，只能用语音、托盘菜单或设置调回 |
| 全屏时保持显示 | 压在无边框全屏的游戏 / 视频上面；关闭则全屏时隐藏，退出全屏后自动出现 |
| 跟着我打字 | 你打字时她也坐下来敲键盘；只统计按键次数，不记录按了什么 |

**声音**

| 项目 | 说明 |
|---|---|
| 说话时播放语音 | 摸头、投喂、被甩飞、打招呼等时候，她会用语音说一句台词，气泡显示同一句；关掉后只显示气泡 |
| 语音音量 | 在系统音量的基础上再调节 |

**语音输入**

| 项目 | 说明 |
|---|---|
| 语音输入 | 按住快捷键（默认右 Ctrl）说话，松开就发给她；在本机识别，声音不上传，会自动加标点 |
| 语音输入快捷键 | 点一下输入框再按想用的键，任意单键或组合键都行 |
| 语音识别模型 | 安装包已自带（约 960MB），打开「语音输入」就能用；删掉后可以点「下载模型」重新下载（约 800MB，从 GitHub 下载，慢的话先填代理地址） |
| 语音唤醒 | 不用按键，喊「小龙娘」「龙娘」「GPT龙娘」叫她：3 秒内开口就接着听，说完停顿 1.5 秒自动发送，按语音输入快捷键马上发送，3 秒没开口就算了。开着时麦克风一直开着，都在本机识别，不上传 |
| 自定义唤醒词 | 可以不填；填好后点「录音适配」，照提示喊 3 遍，适配好后只认这个词（比如填「贾维斯」，喊小龙娘就不会唤醒），没适配上就用默认唤醒词 |

**更新**：显示当前版本，可以手动检查更新、打开 Releases 页面。

**人设与记忆**（主设置里点「人设与记忆」进入）

| 项目 | 说明 |
|---|---|
| 名字 / 怎么称呼你 / 关于我 | 她叫什么、怎么叫你，以及你是谁、在做什么、作息和喜好 |
| 人格设定 / 说话风格 | 她是什么性格、用什么口吻说话 |
| 记忆条数 | 保留最近多少条对话作为上下文，重启后也还在 |
| 长期记忆 | 每聊 10 条整理一次，记下你的喜好、最近的事和你们的约定；「她记得的事」可以手动修改或清空 |
| 主动搭话 | 20~40 分钟没聊天、你在用电脑时，她偶尔会主动找你说一句 |

**她能做什么**（主设置里点「她能做什么」进入）

| 项目 | 说明 |
|---|---|
| 知道我在用什么 | 聊天时带上你最近在用的软件和窗口标题（会发给接口服务商，不截图） |
| 看屏幕 | 默认关闭。打开后右键菜单多出「看看我的屏幕」，聊天时问到屏幕上的东西她也会截图看；可以单独选识图模型，设「不看名单」 |
| 帮我做事 | 默认打开。让她帮你操作电脑，见下面「让她帮你做事」 |
| 允许她操作的软件 | 在「帮我做事」下面，她读过界面、点过按钮的软件都列在这里，可以随时撤销 |
| 浏览器扩展 | 可选，装上后她能操作 Edge / Chrome，见下面；以后扩展有更新会自动重新加载 |
| DSH 连接 | 可选，电脑上装了 DeepSeek Harness 时，写代码、整理文件这类重活交给它在后台做 |

## 让她帮你做事

直接跟她说就行，打字或语音都可以。你直接叫她做的事，她会马上做；她自己提议的事，会先在对话里问你。关机、重启、关掉软件这类操作一定会先确认。说「好了」「不用了」能马上叫停。

| 例子 | 能做什么 |
|---|---|
| 「打开 B 站」「打开下载文件夹」「帮我找一下简历」 | 打开网址、软件、文件和文件夹，找文件 |
| 「十分钟后提醒我喝水」「帮我记个待办」「开个番茄钟」 | 提醒、待办、番茄钟 |
| 「音量调到 30」「网易云小声点」「下一首」「现在放的是什么歌」 | 系统音量、麦克风、单个软件的音量，控制播放 |
| 「网易云放一首晴天」 | 叫网易云放你点名的歌（用你登录的账号） |
| 「把微信最小化」「把这个窗口挪到另一块屏幕」「重启一下网易云」 | 最小化 / 最大化 / 关闭窗口、置顶、换屏幕，关掉或重启软件 |
| 「切到深色模式」「锁屏」「电脑现在卡不卡」 | 深色 / 浅色模式、锁屏，列出最占资源的程序 |
| 「打开 Steam 上的 ××」 | 启动 Steam 游戏、打开商店页 |
| 「按一下 F5」「按住 W 三秒」「按住 Shift 和 W 别松」「松开」 | 往窗口按键、按住一个或几个键，游戏里也能收到 |
| 「点一下左键」「连点十下」「一直按住左键」「松开鼠标」 | 在鼠标现在的位置单击、双击、连点、按住、松开 |
| 「在网易云里点我喜欢的音乐」 | 读软件界面上的按钮和输入框帮你点击、填字，读不到时按截图找位置点；能操作任务栏、托盘和右键菜单。第一次操作某个软件、点付款删除发送类按钮前会先问 |
| 「明天北京天气怎么样」「帮我搜一下 ××」 | 天气、网页搜索 |

不想让她碰电脑：设置 →「她能做什么」→「帮我做事」，把开关关掉。

### 浏览器扩展（可选）

装上后她能直接操作 Edge 或 Chrome：总结网页和选中的文字、点按钮填字、切换和关闭标签页、前进后退、页内查找、控制网页视频（暂停、快进、倍速、调音量）、网页截图、查收藏夹。

安装方法（只要装一次）：

1. 设置 →「她能做什么」→「浏览器扩展」，点「安装浏览器扩展」，会自动打开浏览器的扩展页，扩展文件夹的位置也已经复制好了。
2. 打开「开发人员模式」：Edge 在扩展页左下角，Chrome 在右上角（叫「开发者模式」）。
3. 点「加载解压缩的扩展」，在弹出窗口的地址栏里按 Ctrl+V 粘贴，回车，再点「选择文件夹」。
4. 回到设置，看到「已连接」就好了。

她读到的网页内容会发给接口服务商；密码框里的内容她读不到，网银、支付这类页面她不会碰。

## 和她互动

她有 90 多句语音台词，被摸、被拎起、落地、偷看、吃东西、犯困、睡醒时都会随机说一句。上一句还没说完时不会被新的一句打断。

| 操作 | 效果 |
|---|---|
| 点头部 | 摸头，好感度 +1，飘出爱心 |
| 点腿部 | 嫌弃地躲开 |
| 点身体 | 开心一下 |
| 拖动 | 把她拎起来；松手后按甩动的速度飞出去，撞到屏幕边缘会反弹，摔得重会摔坐在地上，特别重会晕一会儿 |
| 鼠标在旁边移动 | 360° 转头看向鼠标（需开启「跟随鼠标」） |
| 鼠标在屏幕左、右、上边缘停一秒 | 从鼠标旁边那条边探出来偷看，鼠标走开后缩回去（需开启「边缘偷看」） |
| 拖到屏幕左、右、上边缘松手 | 固定在边缘偷看，点她也不回来，拖出来才回来 |
| 甩到窗口上方，或在窗口顶边上方轻放 | 站在窗口顶上，挪动窗口她会跟着走（需开启「站在窗口上」） |
| 拖到窗口左、右边缘松手 | 从窗口后面探头，挪动窗口她跟着走，窗口变得太矮或关掉时掉回地面（需开启「站在窗口上」和「边缘偷看」） |
| 双击对话气泡 | 关闭气泡 |
| **右键** | 打开菜单 |
| 托盘图标左键 | 显示 / 隐藏小龙娘 |

## 养成

- **饱食度**：每 5 分钟下降 1 点，关掉程序期间也会下降。低于 30 时她会饿肚子；高于 90 时吃不下，会拒绝投喂。
- **好感度**：摸头、聊天、投喂都会增加，喂青椒会减少。每 100 点升一级，升级时她会比心，当前等级显示在右键菜单第一行。饱食度降到 0 时，好感度也会慢慢下降。
- **委屈**：好感度低于 20，或者超过一天没理她，她会抱着膝盖委屈地坐着等你。
- **作息**：60 秒没人理她会睡觉；每次启动按时段打招呼，深夜还会打着哈欠催你早点睡。

## 更新

每次启动时会自动检查一次，发布了新版本会弹出「发现新版本」，显示这次的更新说明：

1. 点「下载并安装」，在后台下载，进度显示在托盘图标的提示里（鼠标移到托盘图标上查看）。下载时会尽量只下载改动的部分。
2. 下载完弹出提示：点「立即安装」会先关闭小龙娘，装好后自动重新打开；点「退出时安装」则下次退出时自动安装。设置和养成数值都会保留。

国内访问 GitHub 不稳定，检查或下载失败时，可以在设置里填代理地址，或者点「打开 Releases 页面」用浏览器手动下载安装包，直接覆盖安装即可。

## 常见问题

**玩全屏游戏 / 看全屏视频时她不见了？**
默认全屏时隐藏，退出全屏后会自动出现。想让她一直在，开启「全屏时保持显示」，或者把置顶调到高档。独占全屏的游戏任何窗口都盖不上去，可以在游戏设置里改成「无边框窗口」或「窗口化全屏」。

**鼠标点不到她？**
可能是置顶调到了高档，跟她说「置顶调到中档」，或者在托盘图标上右键改回来。

**语音输入没反应？**
确认设置里打开了「语音输入」并下载好了模型，麦克风能用；按住快捷键说话，说完再松开。

**喊她没反应？**
确认设置 →「语音输入」里打开了「语音唤醒」，麦克风能用。适配过自定义唤醒词后只认那个词，想换回默认的「小龙娘」，把自定义唤醒词清空再保存。她正在回话时不会被唤醒。

**点「读取模型」提示返回的不是模型列表？**
API 地址通常要以 `/v1` 结尾，检查一下是否漏掉了。

**聊天没有反应或报错？**
检查 API Key、API 地址、模型三项是否正确，以及电脑能否访问该接口（需要代理时在设置里填写代理地址）。错误信息会显示在气泡里。

**我的 API Key 安全吗？**
API Key 只保存在电脑本地，聊天请求直接从电脑发往你填写的接口地址，不经过任何第三方服务器。语音识别在本机完成，声音不上传。

**数据存在哪里？**
设置、聊天记录、记忆、提醒和养成数值在 `%APPDATA%\GPT桌宠\`，覆盖安装、应用内更新、卸载重装都不会丢失。为了增量更新，`%LOCALAPPDATA%\gpt-desktop-pet-updater\` 里会保留一份安装包（约 1.9GB），卸载后可以手动删除。

**怎么卸载？**
Windows 设置 →「应用」→ 找到 GPT桌宠 → 卸载。

## 关于

小龙娘的每个动作都由 AI 视频模型生成，经过抠图和补帧做成 60 帧动画，语音由微软 晓伊 音色合成；桌面版基于 Electron 开发。本项目是 **vibe coding** 作品：hkking 提需求、试用和把关，代码和文档由 AI 编写。欢迎在 [Issues](https://github.com/hkk1121/hkking-desktop/issues) 反馈问题和建议。
